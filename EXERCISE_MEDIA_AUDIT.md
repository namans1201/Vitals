# Exercise media audit

Audited the 79 generated PNGs against the exercise prompt specifications using five labeled contact sheets and targeted full-resolution inspection.

## Findings

- `inverted-row.png` — **needs regeneration**. The start panel highlights the pectoral/chest area, while the prompt requires the mid-back/rhomboids/mid-trapezius to be the only highlighted muscle in both panels. The working position also changes the visible highlight inconsistently between panels.
- The other audited generated assets had no clear gross mismatch in the requested exercise, equipment, start/end positions, or highlighted target muscle at contact-sheet resolution.
- This is a visual asset audit, not a medical or biomechanics certification.
